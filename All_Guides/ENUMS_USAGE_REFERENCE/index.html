    ENUMs Usage Reference — MT5Account (Java)¶

    ENUM presence lookup table for all MT5Account low-level methods. Enum type names are the proto/Java names; enum values are shown as their Java constants — the UPPER_SNAKE proto names (e.g. AccountInfoDoublePropertyType.ACCOUNT_BALANCE). All enum types live in the mt5_term_api package, inside the Mt5TermApi… message classes.

    Important Notes¶

    Java ENUM Access¶

    Enums live in the mt5_term_api package inside the Mt5TermApi… message classes, and are used directly as Java enum constants (UPPER_SNAKE names):

    import mt5_term_api.Mt5TermApiAccountInformation.AccountInfoDoublePropertyType;
import mt5_term_api.Mt5TermApiMarketInfo.SymbolInfoDoubleProperty;
import mt5_term_api.Mt5TermApiTradingHelper;

// Account double property — value getter is getRequestedValue()
double balance = account.accountInfoDouble(AccountInfoDoublePropertyType.ACCOUNT_BALANCE)
    .getData().getRequestedValue();

// Symbol double property — value getter is getValue()
double bid = account.symbolInfoDouble("EURUSD", SymbolInfoDoubleProperty.SYMBOL_BID)
    .getData().getValue();

// Enum inside a request object
var request = Mt5TermApiTradingHelper.OrderSendRequest.newBuilder()
    .setSymbol("EURUSD")
    .setOperation(Mt5TermApiTradingHelper.TMT5_ENUM_ORDER_TYPE.TMT5_ORDER_TYPE_BUY)
    .setVolume(0.10)
    .build();

    ⚠️ Mind the value getter. For account properties the reply value is getData().getRequestedValue(); for symbol properties it is getData().getValue(). They are not interchangeable.

    Proto vs Java names. The generated Java constant is the proto OriginalName in UPPER_SNAKE (ACCOUNT_BALANCE). Sibling SDKs in other languages may render the same value in their own casing (e.g. C# AccountBalance) — on the wire it is the same enum.

    Special Cases¶

    1. AccountInfoInteger / SymbolInfoInteger — some properties represent an enum but come back as long/int; they are plain numbers you interpret, not typed enums in the reply.
    2. returnedCode — the returnedCode field in trading replies is not an enum; it is a plain int trade return code (10009 = done; see Return Codes).
    3. Timeframe — chart/quote-history timeframes are carried as the MQL5 ENUM_TIMEFRAMES integer value (e.g. PERIOD_H1 = 16385), not a generated Java enum.
