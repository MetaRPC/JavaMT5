# 💰 MT5Service — Account Information (Mid-Level API)

> Account balance, equity, margin, leverage and identity. The `accountInfo*` wrappers return the **primitive value directly** (not the `Reply`), and ten named convenience getters wrap the most common properties so you never touch an enum.

**Layer:** MID — wrappers over [`MT5Account` · Account Information](../MT5Account/1.%20Account_information/Account_Information.Overview.md).

---

## Value at a glance

| Method | Direct-use value |
|--------|------------------|
| `getBalance()` `getEquity()` `getMargin()` `getFreeMargin()` `getProfit()` `getLogin()` `getLeverage()` `getAccountName()` `getServerName()` `getCurrency()` | ✅ named one-liners — no property enum needed |
| `accountSummary()` | ⚪ unwrap → `AccountSummaryData` (21 fields in one call) |
| `accountInfoDouble/Integer/String(property)` | ⚪ unwrap → `double` / `long` / `String` (`getRequestedValue()`) |

> For many properties at once, prefer `accountSummary()` (one RPC). For a single property, the named getter or `accountInfo*` is identical to calling `MT5Account` directly.

## Methods

|--------|---------|----------------|
| `accountSummary()` | `AccountSummaryData` | `account.accountSummary().getData()` |

| `accountInfoInteger(propertyType)` | `long` | `account.accountInfoInteger(propertyType).getData().getRequestedValue()` |
| `accountInfoString(propertyType)` | `String` | `account.accountInfoString(propertyType).getData().getRequestedValue()` |
| `getBalance()` | `double` | `accountInfoDouble(ACCOUNT_BALANCE)` |
| `getEquity()` | `double` | `accountInfoDouble(ACCOUNT_EQUITY)` |
| `getMargin()` | `double` | `accountInfoDouble(ACCOUNT_MARGIN)` |
| `getFreeMargin()` | `double` | `accountInfoDouble(ACCOUNT_MARGIN_FREE)` |

## 🔗 Usage

```java
MT5Service service = new MT5Service(account);
service.connect("demo.mt5server.com", 443, "EURUSD");

// Named getters — no enum, no .getData()
System.out.printf("Balance:  %.2f %s%n", service.getBalance(), service.getCurrency());
System.out.printf("Equity:   %.2f%n", service.getEquity());
System.out.printf("Leverage: 1:%d%n", service.getLeverage());

// Whole snapshot in one call
var s = service.accountSummary();   // AccountSummaryData
System.out.printf("Login %d, free margin %.2f, margin level %.2f%%%n",
    s.getAccountLogin(), s.getAccountMarginFree(), s.getAccountMarginLevel());

// Single arbitrary property (identical to account.accountInfoDouble(...).getData().getRequestedValue())
double assets = service.accountInfoDouble(
    Mt5TermApiAccountInformation.AccountInfoDoublePropertyType.ACCOUNT_ASSETS);
```
