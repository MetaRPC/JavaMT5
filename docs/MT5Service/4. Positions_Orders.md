# 📋 MT5Service — Positions & Orders (Mid-Level API)

> Count open positions, list open positions/pending orders, and read order/position history. Every wrapper returns the **unwrapped `…Data`** object. Two extra conveniences: a no-arg `openedOrders()` (default sort) and cursor-paged `…Utc` history variants.

**Layer:** MID — wrappers over [`MT5Account` · Positions & Orders](../MT5Account/3.%20Positions_and_orders/Positions_And_Orders.Overview.md).

---

## Value at a glance

| Method | Direct-use value |
|--------|------------------|
| `openedOrders()` (no-arg) | ✅ supplies a default sort (`BMT5_OPENED_ORDER_SORT_BY_OPEN_TIME_ASC`) |
| `positionsTotal` `openedOrders(sortType)` `openedOrdersTickets` `orderHistory` `orderHistoryUtc` `positionsHistory` `positionsHistoryUtc` | ⚪ unwrap → `…Data` |

---

## Methods

| Method | Returns | Implementation |
|--------|---------|----------------|
| `positionsTotal()` | `PositionsTotalData` | `account.positionsTotal().getData()` |
| `openedOrders(sortType)` | `OpenedOrdersData` | `account.openedOrders(sortType).getData()` |
| `openedOrders()` | `OpenedOrdersData` | `openedOrders(BMT5_OPENED_ORDER_SORT_BY_OPEN_TIME_ASC)` |
| `openedOrdersTickets()` | `OpenedOrdersTicketsData` | `account.openedOrdersTickets().getData()` |
| `orderHistory(from, to, sortType, pageNumber, itemsPerPage)` | `OrdersHistoryData` | `account.orderHistory(...).getData()` |
| `orderHistoryUtc(fromUtc, toUtc, sortType, pageToken, pageSize)` | `OrdersHistoryData` | `account.orderHistoryUtc(...).getData()` — cursor-paged |
| `positionsHistory(sortType, from, to, pageNumber, itemsPerPage)` | `PositionsHistoryData` | `account.positionsHistory(...).getData()` |
| `positionsHistoryUtc(sortType, fromUtc, toUtc, pageToken, pageSize)` | `PositionsHistoryData` | `account.positionsHistoryUtc(...).getData()` — cursor-paged |

> Reminders from the low-level layer: `PositionsTotalData` → `getTotalPositions()`; `OpenedOrdersData` → `getPositionInfosList()` + `getOpenedOrdersList()`; `OrdersHistoryData` → `getHistoryDataList()` of `HistoryData` (each has `getHistoryOrder()` / `getHistoryDeal()`); `PositionsHistoryData` → `getHistoryPositionsList()`.

**Parameter enums** (`BMT5_ENUM_OPENED_ORDER_SORT_TYPE`, `BMT5_ENUM_ORDER_HISTORY_SORT_TYPE`, `AH_ENUM_POSITIONS_HISTORY_SORT_TYPE`) and all element fields are documented once:

## 🔗 Usage

```java
MT5Service service = new MT5Service(account);

// Count
System.out.println("Open positions: " + service.positionsTotal().getTotalPositions());

// All open positions & pending orders (default sort)
var data = service.openedOrders();
for (var pos : data.getPositionInfosList()) {
    System.out.printf("#%d %s %.2f lots, P/L %.2f%n",
        pos.getTicket(), pos.getSymbol(), pos.getVolume(), pos.getProfit());
}

// History (last 7 days)
var now = com.google.protobuf.Timestamp.newBuilder()
        .setSeconds(java.time.Instant.now().getEpochSecond()).build();
var weekAgo = com.google.protobuf.Timestamp.newBuilder()
        .setSeconds(java.time.Instant.now().minusSeconds(7*86400).getEpochSecond()).build();

var ph = service.positionsHistory(
    Mt5TermApiAccountHelper.AH_ENUM_POSITIONS_HISTORY_SORT_TYPE.AH_POSITION_OPEN_TIME_DESC,
    weekAgo, now, 0, 0);
System.out.println("Closed positions: " + ph.getHistoryPositionsList().size());
```
