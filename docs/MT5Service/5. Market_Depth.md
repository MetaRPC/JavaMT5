# 📖 MT5Service — Market Depth / DOM (Mid-Level API)

> Subscribe to Level II (Depth of Market), pull the current order book, unsubscribe. `marketBookGet(...)` returns the **unwrapped `MarketBookGetData`**; the add/release calls are plain `void` pass-throughs.

**Layer:** MID — wrappers over [`MT5Account` · Market Depth (DOM)](../MT5Account/4.%20Market_depth_DOM/Market_Depth_DOM.Overview.md).

---

## Value at a glance

| Method | Direct-use value |
|--------|------------------|
| `marketBookGet(symbol)` | ⚪ unwrap → `MarketBookGetData` |
| `marketBookAdd(symbol)` / `marketBookRelease(symbol)` | ⛔ pure pass-through (`void`) |

---

## Methods

| Method | Returns | Implementation |
|--------|---------|----------------|
| `marketBookAdd(symbol)` | `void` | `account.marketBookAdd(symbol)` |
| `marketBookGet(symbol)` | `MarketBookGetData` | `account.marketBookGet(symbol).getData()` |
| `marketBookRelease(symbol)` | `void` | `account.marketBookRelease(symbol)` |

`MarketBookGetData` → `getMqlBookInfosList()` of `MrpcMqlBookInfo` (`getType()` → `BookType`, `getPrice()`, `getVolume()`, `getVolumeReal()`). Full field/enum detail: [MarketBookGet](../MT5Account/4.%20Market_depth_DOM/MarketBookGet.md).

---

## 🔗 Usage

```java
MT5Service service = new MT5Service(account);

service.marketBookAdd("EURUSD");                  // subscribe first
try {
    var book = service.marketBookGet("EURUSD");   // MarketBookGetData
    for (var entry : book.getMqlBookInfosList()) {
        String side = entry.getType().getNumber() == 1 ? "BID" : "ASK";  // BookType BUY=1
        System.out.printf("%s %.5f  vol=%d%n", side, entry.getPrice(), entry.getVolume());
    }
} finally {
    service.marketBookRelease("EURUSD");          // always unsubscribe
}
```
