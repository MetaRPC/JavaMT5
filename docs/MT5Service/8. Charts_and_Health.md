# 🩺 MT5Service — Charts & Health (Mid-Level API)

> Open/close internal terminal charts and check terminal health. These are **mid-level–only** helpers. `openChartForSymbol` and `getServerTime` unwrap to a primitive; `healthCheck` returns the **full reply** and `closeChartForSymbol`/`stopListening` are `void` pass-throughs.

**Layer:** MID — wrappers over `MT5Account` chart / health methods.

---

## Value at a glance

| Method | Direct-use value |
|--------|------------------|
| `openChartForSymbol(...)` | ⚪ unwrap → `long` chart id (`getMqlChartId()`) |
| `getServerTime()` | ✅ `account.healthCheck().getServerTimeSeconds()` → `long` |
| `healthCheck()` | ⛔ pass-through — returns the full `HealthCheckReply` |
| `closeChartForSymbol(id)` / `stopListening()` | ⛔ pure pass-through (`void`) |

---

## Methods

| Method | Returns | Implementation |
|--------|---------|----------------|
| `openChartForSymbol(symbolName, expertMode, timerPeriod, ignoreEmptyData)` | `long` | `account.openChartForSymbol(...).getMqlChartId()` |
| `closeChartForSymbol(mqlChartId)` | `void` | `account.closeChartForSymbol(mqlChartId)` |
| `healthCheck()` | `HealthCheckReply` | `account.healthCheck()` |
| `getServerTime()` | `long` | `account.healthCheck().getServerTimeSeconds()` |
| `stopListening()` | `void` | `account.stopListening()` |

- `openChartForSymbol` — `expertMode` is a `ChartExpertMode`; `timerPeriod` (`Integer`) and `ignoreEmptyData` (`Boolean`) are nullable. Returns the new chart's MQL id; keep it to close the chart later.
- `healthCheck()` returns the raw `HealthCheckReply` (server time, alive flag, version, …) — the one wrapper that intentionally does **not** unwrap, so you get the full payload. `getServerTime()` is the shortcut for just the server time (Unix seconds).
- `stopListening()` asks the terminal to stop pushing subscription events. Also see [gRPC Channel & Stream Management](../All_Guides/GRPC_CHANNEL_AND_STREAM_MANAGEMENT_EN.md) for proper stream shutdown.

---

## 🔗 Usage

```java
MT5Service service = new MT5Service(account);

// Health
if (service.isConnected()) {
    System.out.println("Server time (Unix s): " + service.getServerTime());
    var hc = service.healthCheck();   // full reply
    System.out.println("Alive: " + hc.getData().getHealthCheck().getIsAlive());
}

// Internal chart lifecycle
long chartId = service.openChartForSymbol(
    "EURUSD",
    Mt5TermApiInternalCharts.ChartExpertMode.ON_TICK, // which terminal events drive the chart expert
    1000,    // timer period (ms), nullable
    false);  // ignoreEmptyData, nullable
// … use the chart …
service.closeChartForSymbol(chartId);
```

> **`ChartExpertMode`** values: `ON_TICK`(0), `ON_TRADE`(1), `ON_ORDER_PROFIT`(2), `ON_OPENED_ORDERS_TICKETS`(3), `ON_TRADE_TRANSACTION`(4), `EVENTS`(5). `HealthCheckReply` fields come from the generated `Mt5TermApiHealthCheck` proto.
