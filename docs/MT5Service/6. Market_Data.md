# 🕯️ MT5Service — Market Data (Mid-Level API)

> Historical bars, the full symbol list, tick value/size, and historical orders. These are **mid-level–only** helpers (no dedicated low-level doc page). The star is **`lastBars(...)`** — it paginates the bar history for you and returns the newest `count` bars.

**Layer:** MID — wrappers over `MT5Account` market-data / quote-history methods.

---

## Value at a glance

| Method | Direct-use value |
|--------|------------------|
| `lastBars(symbol, timeframe, count)` | ✅ **real logic** — walks `QuoteHistory.Bars` pages from a computed look-back window and trims to the newest `count` bars |
| `priceHistory(...)` `symbolList()` | ⚪ unwrap → `List<…>` (`getBarsList()` / `getSymbolsList()`) |
| `quoteHistoryBars(...)` `tickValueWithSize(...)` `allHistoryOrders(...)` | ⚪ unwrap → `…Data` |

---

## Methods

| Method | Returns | Implementation |
|--------|---------|----------------|
| `lastBars(symbol, timeframe, count)` | `List<QuoteHistoryBar>` | paginates `quoteHistoryBars(...)` and keeps the last `count` |
| `quoteHistoryBars(symbol, timeframe, fromTimeUtc, toTimeUtc, pageSize, pageToken)` | `QuoteHistoryBarsData` | `account.quoteHistoryBars(...).getData()` |
| `priceHistory(symbol, mqlTimeframe, fromTimeUtc, toTimeUtc, maxBars)` | `List<PriceBar>` | `account.priceHistory(...).getData().getBarsList()` |
| `symbolList()` | `List<String>` | `account.symbolList().getData().getSymbolsList()` |
| `tickValueWithSize(symbolNames)` | `TickValueWithSizeData` | `account.tickValueWithSize(symbolNames).getData()` |
| `allHistoryOrders(fromUtc, toUtc, sortType, pageToken, pageSize)` | `AllHistoryOrdersData` | `account.allHistoryOrders(...).getData()` |

### `QuoteHistoryBar` / `PriceBar` fields

Both bar types expose the same getters:

| Getter | Type | Meaning |
|--------|------|---------|
| `getTime()` / `getTimeUtc()` | `long` | Bar open time (Unix seconds) |
| `getOpen()` `getHigh()` `getLow()` `getClose()` | `double` | OHLC prices |
| `getTickVolume()` | `long` | Tick volume |
| `getRealVolume()` | `long` | Real (exchange) volume |
| `getSpread()` | `int` | Spread in points |

### Enum: `QUOTE_HISTORY_TIMEFRAME` (bar length; number = minutes)

`QH_PERIOD_M1`(1), `M2`(2), `M3`(3), `M4`(4), `M5`(5), `M6`(6), `M10`(10), `M12`(12), `M15`(15), `M20`(20), `M30`(30), `QH_PERIOD_H1`(60), `H2`(120), … up to the daily/weekly/monthly periods. `QH_PERIOD_UNSPECIFIED`(0) is the unset default.

> `lastBars` uses `timeframe.getNumber()` (minutes) to size its look-back window: `max(3 days, 4 × count × minutes × 60)` seconds, so weekend/holiday gaps still yield enough bars.

`tickValueWithSize` → `getSymbolTickSizeInfosList()` of `TickSizeSymbol`; see the low-level [TickValueWithSize](../MT5Account/2.%20Symbol_information/TickValueWithSize.md) for its fields.

## 🔗 Usage

```java
MT5Service service = new MT5Service(account);

// Newest 200 M15 bars — pagination handled for you
var bars = service.lastBars("EURUSD",
    Mt5TermApiQuoteHistory.QUOTE_HISTORY_TIMEFRAME.QH_PERIOD_M15, 200);
for (var b : bars) {
    System.out.printf("%d  O=%.5f H=%.5f L=%.5f C=%.5f  vol=%d%n",
        b.getTime(), b.getOpen(), b.getHigh(), b.getLow(), b.getClose(), b.getTickVolume());
}

// Every symbol the broker offers
java.util.List<String> symbols = service.symbolList();
System.out.println("Broker symbols: " + symbols.size());

// Tick value for risk sizing
var tv = service.tickValueWithSize(new String[]{"EURUSD", "XAUUSD"});
tv.getSymbolTickSizeInfosList().forEach(i ->
    System.out.printf("%s: tickValue=%.5f%n", i.getName(), i.getTradeTickValue()));
```
