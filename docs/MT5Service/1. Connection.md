# 🔌 MT5Service — Connection (Mid-Level API)

> Open, check, re-open and close the terminal session. Each wrapper returns the **unwrapped `…Data`** object (not the `…Reply`); `isConnected()` goes one step further and returns a plain `boolean`.

**Layer:** MID — thin wrappers over [`MT5Account`](../MT5Account/1.%20Account_information/Account_Information.Overview.md) connection methods.

---

## Value at a glance

| Method | Direct-use value |
|--------|------------------|
| `isConnected()` | ✅ digs `checkConnect().getData().getHealthCheck().getIsAlive()` → `boolean` |
| `connect(...)` / `connectByServerName(...)` / `connectProxy(...)` / `reconnect(...)` | ⚪ unwrap `Reply` → `…Data` |
| `disconnect()` / `disconnect(delete)` | ⛔ pure pass-through (`void`) |

---

## Methods

| Method | Returns | Implementation |
|--------|---------|----------------|
| `connect(host, port, baseChartSymbol, waitForTerminalIsAlive, timeoutSeconds)` | `ConnectData` | `account.connect(...).getData()` |
| `connect(host, port, baseChartSymbol)` | `ConnectData` | `account.connect(...).getData()` |
| `connectByServerName(serverName, baseChartSymbol, timeoutSeconds)` | `ConnectData` | `account.connectByServerName(...).getData()` |
| `connectByServerName(serverName, baseChartSymbol)` | `ConnectData` | `account.connectByServerName(...).getData()` |
| `connectByServerName(serverName, baseChartSymbol, timeoutSeconds, name)` | `ConnectData` | `account.connectByServerName(...).getData()` |
| `isConnected()` | `boolean` | `account.checkConnect().getData().getHealthCheck().getIsAlive()` |
| `disconnect()` | `void` | `disconnect(false)` |
| `disconnect(delete)` | `void` | `account.disconnect(delete)` |
| `connectProxy(host, port, proxyUser, proxyPassword, proxyHost, proxyPort, proxyType, baseChartSymbol, waitForTerminalIsAlive, timeoutSeconds)` | `ConnectProxyData` | `account.connectProxy(...).getData()` |
| `reconnect(forceReconnection, timeoutSeconds)` | `ReconnectData` | `account.reconnect(...).getData()` |

`ConnectData` exposes `getTerminalInstanceGuid()` (`String`) and `getTerminalType()` (`TerminalType` enum).

### Enum: `ProxyTypes` (for `connectProxy`)

| Value | Number | Meaning |
|-------|--------|---------|
| `None` | 0 | No proxy |
| `Https` | 1 | HTTPS proxy |
| `Socks4` | 2 | SOCKS4 proxy |

---

## 🔗 Usage

```java
MT5Account account = new MT5Account(12345678, "password");
MT5Service service = new MT5Service(account);

// By host/port (3-arg convenience overload)
var data = service.connect("demo.mt5server.com", 443, "EURUSD");
System.out.println("Terminal GUID: " + data.getTerminalInstanceGuid());

// …or by broker server name
// service.connectByServerName("MetaQuotes-Demo", "EURUSD");

if (service.isConnected()) {
    System.out.println("✅ Session alive");
}

// When finished
service.disconnect();   // detach terminal (delete=false)
service.close();        // release the gRPC channel
```

> **Tip:** `connect(...)` returns `ConnectData`, not the full `ConnectReply`. If you need `hasError()`/`getError()` handling on the raw reply, call `service.getAccount().connect(...)`.
