# 📤 MT5Service — Trading Operations (Mid-Level API)

> Place, modify and close orders, plus margin/profit calculation and pre-trade validation. The order wrappers return the **unwrapped `…Data`** (not the `…Reply`), and the calc wrappers return a plain `double`.

**Layer:** MID — wrappers over [`MT5Account` · Trading](../MT5Account/5.%20Trading/Trading.Overview.md).

---

## Value at a glance

| Method | Direct-use value |
|--------|------------------|
| `orderClose(request)` | ✅ unpacks an `OrderCloseRequest` into `(ticket, volume, slippage)` for you |
| `orderSend` `orderModify` `orderClose(ticket, volume, slippage)` `orderCheck` | ⚪ unwrap → `…Data` |
| `orderCalcMargin` `orderCalcProfit` | ⚪ unwrap → `double` |

> Every result still carries `getReturnedCode()` — check it for `10009` (done) exactly as with `MT5Account`.

---

## Methods

| Method | Returns | Implementation |
|--------|---------|----------------|
| `orderSend(request)` | `OrderSendData` | `account.orderSend(request).getData()` |
| `orderModify(request)` | `OrderModifyData` | `account.orderModify(request).getData()` |
| `orderClose(ticket, volume, slippage)` | `OrderCloseData` | `account.orderClose(ticket, volume, slippage).getData()` |
| `orderClose(request)` | `OrderCloseData` | unpacks `request.getTicket()/getVolume()/getSlippage()` → `account.orderClose(...)` |
| `orderCalcMargin(symbol, orderType, volume, openPrice)` | `double` | `… .getData().getMargin()` |
| `orderCalcProfit(symbol, orderType, volume, openPrice, closePrice)` | `double` | `… .getData().getProfit()` |
| `orderCheck(tradeRequest)` | `OrderCheckData` | `account.orderCheck(tradeRequest).getData()` |

> Builders & enums are the same as the low-level layer: `OrderSendRequest` (operation = `TMT5_ENUM_ORDER_TYPE`), `OrderModifyRequest`, `OrderCloseRequest`, `ENUM_ORDER_TYPE_TF` (calc), `MrpcMqlTradeRequest` (check). `OrderCheckData` → `getMqlTradeCheckResult()` (`MrpcMqlTradeCheckResult`: margin, free_margin, balance/equity after, …).

## 🔗 Usage

```java
MT5Service service = new MT5Service(account);

// Open a market BUY — orderSend returns OrderSendData (already unwrapped)
var request = Mt5TermApiTradingHelper.OrderSendRequest.newBuilder()
    .setSymbol("EURUSD")
    .setOperation(Mt5TermApiTradingHelper.TMT5_ENUM_ORDER_TYPE.TMT5_ORDER_TYPE_BUY)
    .setVolume(0.10)
    .setSlippage(10)
    .build();

var res = service.orderSend(request);   // OrderSendData
if (res.getReturnedCode() == 10009) {
    System.out.printf("✅ Opened, order #%d @ %.5f%n", res.getOrder(), res.getPrice());
}

// Pre-trade margin as a plain double
double margin = service.orderCalcMargin(
    "EURUSD", Mt5TermApiTradeFunctions.ENUM_ORDER_TYPE_TF.ORDER_TYPE_TF_BUY, 0.10, res.getPrice());
System.out.printf("Margin required: %.2f%n", margin);

// Close fully
service.orderClose(res.getOrder(), 0.0, 10);   // OrderCloseData
```
