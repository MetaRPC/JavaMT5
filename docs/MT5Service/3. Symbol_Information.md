# 📈 MT5Service — Symbol Information (Mid-Level API)

> Quotes, symbol properties, trading conditions and session schedules. Most wrappers return the **unwrapped `…Data`** (or a primitive); `quoteMany(...)` is a pure pass-through that returns the raw reply array.

**Layer:** MID — wrappers over [`MT5Account` · Symbol Information](../MT5Account/2.%20Symbol_information/Symbol_Information.Overview.md).

---

## Value at a glance

| Methods | Direct-use value |
|---------|------------------|
| `symbolsTotal` `symbolSelect` `symbolExist` `symbolName` `symbolIsSynchronized` | ⚪ unwrap → primitive (`int` / `boolean` / `String`) |
| `quote` `symbolInfoTick` `symbolInfoDouble/Integer/String` `symbolInfoMarginRate` `symbolInfoSessionQuote/Trade` `symbolParamsMany` | ⚪ unwrap → `…Data` |
| `quoteMany` | ⛔ pure pass-through — returns `SymbolInfoTickRequestReply[]` unchanged |

---

## Methods

| Method | Returns | Implementation |
|--------|---------|----------------|
| `quote(symbol)` | `MrpcMqlTick` | `account.quote(symbol).getData()` |
| `quoteMany(symbols)` | `SymbolInfoTickRequestReply[]` | `account.quoteMany(symbols)` *(array of replies — unwrap each with `.getData()`)* |
| `symbolsTotal(selectedOnly)` | `int` | `… .getData().getTotal()` |
| `symbolInfoTick(symbol)` | `MrpcMqlTick` | `… .getData()` |
| `symbolSelect(symbol, select)` | `boolean` | `… .getData().getSuccess()` |
| `symbolInfoDouble(symbol, property)` | `SymbolInfoDoubleData` | `… .getData()` |
| `symbolInfoInteger(symbol, property)` | `SymbolInfoIntegerData` | `… .getData()` |
| `symbolInfoString(symbol, property)` | `SymbolInfoStringData` | `… .getData()` |
| `symbolExist(symbolName)` | `boolean` | `… .getData().getExists()` |
| `symbolName(index, selectedOnly)` | `String` | `… .getData().getName()` |
| `symbolIsSynchronized(symbol)` | `boolean` | `… .getData().getSynchronized()` |
| `symbolInfoMarginRate(symbol, orderType)` | `SymbolInfoMarginRateData` | `… .getData()` |
| `symbolInfoSessionQuote(symbol, dayOfWeek, sessionIndex)` | `SymbolInfoSessionQuoteData` | `… .getData()` |
| `symbolInfoSessionTrade(symbol, dayOfWeek, sessionIndex)` | `SymbolInfoSessionTradeData` | `… .getData()` |
| `symbolParamsMany(symbolName, sortType, pageNumber, itemsPerPage)` | `SymbolParamsManyData` | `… .getData()` |

> ⚠️ Note the unwrap getters: `symbolInfoDouble/Integer/String` return **`…Data`** whose value field is read with **`getValue()`** (symbol-info uses `value`, unlike account-info's `getRequestedValue()`).

**Parameter enums** (`SymbolInfoDoubleProperty` 37, `SymbolInfoIntegerProperty` 37, `SymbolInfoStringProperty` 15, `ENUM_ORDER_TYPE`, `DayOfWeek`, `AH_SYMBOL_PARAMS_MANY_SORT_TYPE`) are documented once in the low-level pages:

- [SymbolInfoDouble](../MT5Account/2.%20Symbol_information/SymbolInfoDouble.md) · [SymbolInfoInteger](../MT5Account/2.%20Symbol_information/SymbolInfoInteger.md) · [SymbolInfoString](../MT5Account/2.%20Symbol_information/SymbolInfoString.md)
- [SymbolInfoMarginRate](../MT5Account/2.%20Symbol_information/SymbolInfoMarginRate.md) · [SymbolInfoSessionQuote](../MT5Account/2.%20Symbol_information/SymbolInfoSessionQuote.md) · [SymbolParamsMany](../MT5Account/2.%20Symbol_information/SymbolParamsMany.md)

## 🔗 Usage

```java
MT5Service service = new MT5Service(account);

// Current quote — MrpcMqlTick directly
var tick = service.symbolInfoTick("EURUSD");
System.out.printf("Bid %.5f / Ask %.5f%n", tick.getBid(), tick.getAsk());

// Primitive unwrap
int total = service.symbolsTotal(false);
boolean ok = service.symbolExist("GBPUSD") && service.symbolSelect("GBPUSD", true);

// Single property — returns …Data, read with getValue()
double point = service.symbolInfoDouble(
        "EURUSD", Mt5TermApiMarketInfo.SymbolInfoDoubleProperty.SYMBOL_POINT)
    .getValue();

// quoteMany returns an array of REPLIES — unwrap each
for (var reply : service.quoteMany(new String[]{"EURUSD", "GBPUSD"})) {
    var t = reply.getData();
    System.out.printf("%s %.5f%n", t.getSymbol(), t.getBid());
}
```
